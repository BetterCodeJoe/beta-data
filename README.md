# beta-data

Beta Data: a bilingual (ES/EN) client dashboard and relationship workflow, synced two ways with HubSpot.

- **Client 0:** Centro Cultural Hispano (Ferndale, MI)
- **Beta testers:** project managers, property managers and contractors
- **Stack:** Next.js + shadcn/ui, HubSpot API (`@hubspot/api-client`), deployed on Vercel
